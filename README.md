# KisanWise 
KisanWise is an intelligent agricultural decision support platform designed specifically for Indian farmers to maximize net realization from APMC mandis.


## 🚀 What Was Upgraded in Version 2.0

1. * **Frontend:** Modern modular React 19 + TypeScript + Vite + Tailwind CSS (`/frontend/src`).
   - **Backend:** Production-ready asynchronous Python FastAPI server (`/backend`).
*M -Preserved Original Agricultural Color Palette & Mobile-First UX:**
   - Retained the signature forest emerald (`#1B6E47`), harvest golden amber (`#D97706`), warm sage background (`#FBFBFA`), and clean card styling (`#FFFFFF`).
   - Implemented strict mobile-first design adhering to Vercel Web Interface Guidelines (`touch-action: manipulation`, tabular numbers, safe area insets, 44px+ touch targets).
4. **Real Agricultural Data Pipelines & Services:**
   - **Open-Meteo Integration:** Hyperlocal 7-day weather forecast with rain damage risk warnings.
   - **Agmarknet Mandi Engine:** Live modal rates, arrival volumes, and 30-day historical trend curves.
   - **Net Realization Optimizer:** Distance-based freight deductions and 2% APMC cess calculations comparing Sell Now vs. Wait 7/14 Days.
   - **Multilingual Voice & Chat AI:** Grounded advisor supporting Marathi (मराठी), Hindi (हिंदी), and English with Web Speech API integration.
   - **In-App Notification Center:** Alert feed for price surges, rain warnings, and harvest deadlines.
5. **Password Authentication:**
   - Bcrypt-secured password authentication with JWT session tokens and one-click demo mode bypass.
